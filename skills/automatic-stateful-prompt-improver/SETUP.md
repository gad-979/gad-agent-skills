# Setup and limitations

This package contains instructions and conceptual references. It does not include a working prompt-learning MCP server, a database, or credentials.

For local, non-stateful use, install the skill and ask your agent to improve a prompt. No external server is required for that mode.

For stateful retrieval or feedback, independently select and configure a compatible MCP server in your host, review its privacy and security model, and check the tools and schemas it actually exposes. Consult that server's own documentation for installation and configuration; do not assume that the illustrative server specification in this package is runnable. A server may require separate services or paid APIs.

Do not place API keys in this repository. The availability of stateful learning and any performance improvement have not been verified.

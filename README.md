# GAD agent skills

A collection of agent skills for building agents, improving prompts, and automating browser and desktop workflows.

## Skills

- **agent-creator** — Create custom agents, skills, and MCP integrations.
- **automatic-stateful-prompt-improver** — Optimize prompts using a prompt-learning MCP server; requires that server and its configured dependencies.
- **browser-automation** — Browser and Windows desktop automation workflows; requires the tools referenced by the skill.

Each skill retains its original name and description in its `SKILL.md`. Review its instructions and dependencies before use. Some instructions reference local tooling or other skills that are not included here.
